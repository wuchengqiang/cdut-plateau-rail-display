青藏高原滑轨屏：一次性播放诊断工具（2026-11-02）

用途
在现场电脑自动采集约两分钟数据，不重新打包、替换或升级播放器。
工具调用现场原有的 slider-screen-service.exe，使用原来的配置、视频和播放器专用浏览器配置目录。
只需要 Windows 10/11 自带的 Windows PowerShell 5.1 和 Microsoft Edge。
无需 Python、Node、管理员权限、中控密钥或联网下载安装。

通过 VNC 操作（人在现场可以直接操作）
1. 将工具 ZIP 传到现场电脑桌面，完整解压到一个独立文件夹。不要覆盖原 app，也不要直接在 ZIP 里运行。
2. 等滑轨停止，退出数字人 Host 和原来的独立播放器。厂家控制软件保持打开。
   不要同时留着两个视频播放窗口，否则会增加负载，影响判断。
3. 双击 start-diagnostics.bat。
4. 在选择文件窗口中找到现场播放器：
   通常为 C:\数字人\app\runtime\slider-screen-service.exe
   选择 EXE，不要选 start.bat、数字人 Host.exe 或70周年播放器。
5. 在黑色窗口确认轨道安全后按回车。工具会启动原后台，并自动打开全屏诊断播放页面。
6. 自动采集120秒。你照常手动切换点位，建议每个点位看20～30秒。
   必须等前一个机械动作结束再切下一个；两分钟内不需要强行跑完所有点位。
   可以调音量、暂停、继续。工具不会自动切点、播放、回原点或急停。
   请留意实际屏幕是否卡顿，不要仅依据 VNC 传屏流畅度。
7. 结束后会自动打开报告所在文件夹，选中 report.json。
   只需把这一个 report.json 通过 VNC 文件传输拷回开发电脑，发给本线程。
   默认位置：工具文件夹\reports\日期时间-随机编号\report.json
8. 报告生成时网页和后台先保留。确认滑轨已停止后，切回黑色窗口，按回车结束。
   工具仅关闭它自己启动的网页和后台。然后按你原来的方式启动播放器或数字人 Host。

如果没有复现卡顿
也把 report.json 发回；明确说明“诊断窗口不卡，原启动方式会卡”。
工具复用原独立播放器的专用浏览器配置，并保留原硬件加速设置，
但增加了本机调试连接；此对比只能缩小范围，不能据此认定问题已经修复。
本次工具针对独立播放器，不采集数字人 Host 的内嵌浏览器。

异常情况
- 提示端口被占用或原窗口仍在运行：旧应用没有完全退出。退出旧播放器/Host后重试；不要乱结束所有 Edge 进程。
- 选择文件后启动失败：本次 reports 子目录仍会留下 report.json 和 backend-error.log/backend-out.log。
  优先发送 report.json；若里面提示后台启动失败，再附启动日志。
- 中途关闭诊断网页：工具会尽量保存已有数据，report.json 的 completed 为 false。这种报告也有用。
- 不要直接关闭黑色窗口或强制结束进程。数据每约15秒保存一次，但未保存的末尾数据可能丢失；网页/后台也可能保留。
- 若卡在黑色窗口等待安全确认，使用 Alt+Tab 找到它；VNC需要把组合键发送到远程电脑。
- 如果浏览器策略禁止调试，工具会退出并报告原因，不会修改策略或防火墙。

采集内容与边界
每约1秒：当前点位、机械/播放状态、视频路径（不含URL密钥）、尺寸、进度、缓冲、总帧、丢帧、静音、音量、可见性、窗口尺寸。
事件：视频装载、等待数据、暂停、跳转、结束、错误；点位切换后创建的新视频元素会单独编号。
解码信息：浏览器提供的解码器名称、是否平台解码、音视频轨道等；不支持的项目会标记缺失，不能把缺失当成软件解码。
每约5秒：整机CPU占用和可用内存；另有CPU、GPU型号/驱动和浏览器版本。
不采集密码、中控密钥、视频画面或完整视频，不录屏，不读取其他浏览器标签。
调试端口随机分配，并核验仅监听127.0.0.1/::1；不开放到局域网，不改8000/8001接口或鉴权。
工具不调用任何 POST 播控接口。原EXE启动时仍会按原逻辑初始化厂家连接（PING/状态查询）；你手动切点时会真实移动。
采集结束不会自动急停或回原点，不能代替现场安全措施。
原 EXE、配置、媒体文件不被工具替换；浏览器使用专用目录时仍会按正常方式更新自己的缓存。

开发者维护
源文件：collect.ps1（UTF-8 BOM）、browser-probe.js、CdpConnection.cs、start-diagnostics.bat（ASCII CRLF）。
reports/ 为本机诊断数据，不进入Git或工具ZIP。
自动化参数 UseExistingService/NonInteractive/HeadlessTest 仅供隔离服务测试；日常现场请用BAT，不手动输入这些参数。
此工具不是新的播放器版本，也不包含播放器EXE、配置、媒体或密钥。
