# V1.1.7 播控栏界面补丁（2026-09-17）

适用于已有的 V1.1.7 青藏高原滑轨屏 Web 服务包，不适用于70周年播放器或其他旧版本。

只更新前端页面：播放、暂停、停止使用文字按钮；音量采用短横滑条，静音显示红叉。不会更新 EXE、视频、背景、配置、管理员密码或中控密钥。后端版本仍为 V1.1.7。

## 现场更新

1. 退出数字人 Host，彻底关闭滑轨屏后台服务（仅关闭浏览器不一定关闭后台）。
2. 备份旧文件夹 `app\runtime\_internal\backend\static` 到 app 目录外，方便回退。
3. 解压补丁，把其中的 `app` 文件夹合并到原来的 `app`，允许覆盖同名文件。不要删除或替换整个 app 文件夹，不要套成 app\app。
4. 检查 `app\runtime\_internal\backend\static\index.html` 已更新，并且同目录 assets 中存在它引用的新 JS/CSS 文件。
5. 按原方式启动，浏览器按 Ctrl+F5 强制刷新；数字人内置页面可通过彻底退出并重启 Host 刷新。
6. 检查四号点位视频、播放/暂停、音量拖动、静音红叉，以及数字人预留区。此补丁不改变现场配置或控制接口。

更新失败时，停掉服务，将备份的 static 恢复到原位置，再重新启动。旧的带哈希 JS/CSS 文件可以保留，不影响新页面。

补丁验证使用本机隔离预览，未连接现场电机；仍需现场确认数字人叠加后的触屏效果。
