# 视频放置说明（1.1.3）

交付包的视频目录为 `app/runtime/content/videos`，有效配置是 `app/runtime/config/points.json`，不再使用旧的 `scenes.json`。

| 点位 | 当前页面标题 | 当前 videoPath | 本包素材 |
| --- | --- | --- | --- |
| p01 | 高原启程 | `content/videos/p01.mp4` | 已包含 |
| p02 | 地质巡测 | `content/videos/p02.mp4` | 待放入 |
| p03 | 冰川源区 | `content/videos/p03.mp4` | 待放入 |
| p04 | 高原守望 | `content/videos/p04.mp4` | 待放入 |

视频不必固定命名。使用其他文件名时，将 `points.json` 中对应点位的 `videoPath` 改成实际路径；页面标题、按钮名与介绍分别是 `title`、`navLabel`、`subtitle`，均可修改。保存为 UTF-8，然后重启服务并刷新页面。

Web API 按动作目录关联点位，不靠文件名识别视频。数字人动作文字与关键词在管理员动作配置页维护。

建议 MP4 容器、H.264 视频和 AAC 音频。页面视频框为 16:9，竖版视频等比例显示并留边，不裁切。本包只有 p01 视频；未补齐素材、核实最终原点及坐标前不要开启自动巡展。
