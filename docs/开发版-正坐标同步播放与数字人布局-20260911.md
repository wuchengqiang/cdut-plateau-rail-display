## 播放与移动

选择点位 → 立即装载并播放对应视频 → 同时发送 MOVE → 等待到位回执，仅更新机械位置。

- `displayPointId` 是正在展示的内容；`targetPointId` 是待确认到位的目标；`currentPointId` 仍是上次确认的机械点位，初始值不是传感器实测值。
- 视频开始播放不再代表电机已到位。到位后不会重播视频，也不会取消用户在移动途中点下的暂停或停止。
- 移动超时只报告硬件故障，不切回旧视频、不添加模糊遮罩；已有视频仍可独立播放。
- 移动途中可暂停、停止视频、调整音量；新的点位切换会提示等待，避免并发移动。
- 视频“停止”不等于机械急停；所有现场动作仍需确认行程安全。

## 页面

- 左侧内容区：主题、展项介绍、16:9 横屏视频、播放/暂停/停止/音量、滑轨控制和点位导航。
- 右侧约 30% 预留数字人，关键按钮不会进入这块区域；保留 `avatarAnchor=left` 镜像兼容。
- 独立预览显示“数字人展示区”边界；嵌入模式不显示占位说明和吉祥物，真实数字人由 Host 加载。
- 页面自带玩偶默认关闭：`config/app.json` 中 `"showMascots": false`。缺少该字段的旧配置也默认关闭，加载配置前不会短暂闪出玩偶；图片素材仍保留。
- 如以后需要独立模式的装饰玩偶，可改为 `"showMascots": true`，重启服务并刷新页面。Host 嵌入模式始终隐藏自带玩偶；该开关不控制真实数字人，也不移除右侧预留区。
- 删除视频全屏入口及浏览器 Fullscreen API 调用；独立启动的 Edge 整页全屏保留。
- 移动状态与故障提示在视频下方，不遮挡内容；新增说明文字可在 `config/app.json` 的 `labels` 修改。
- 视频缺失时单独提示，不把缺失素材误报成电机异常。
