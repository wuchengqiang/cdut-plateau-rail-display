# 绿色版外置配置说明

绿色版运行时会直接读取项目根目录的 `config/` 与 `content/`，修改这些文件后在管理员登录时会自动重载配置；也可重启程序。无需重新打包。

## `config/app.json`：全局页面内容

| 字段 | 修改内容 |
| --- | --- |
| `title` | 左上角单位名称 |
| `themeTitle` | 主标题，例如“青藏高原科考” |
| `themeSubtitle` | 展项说明 |
| `brandEnglish` | 主标题旁英文 |
| `coordinatePrimary` / `coordinateSecondary` / `coordinateLabel` | 右上角三段文字 |
| `emblemPath` | 校徽文件路径 |
| `mascots` | 四个玩偶文件路径 |
| `labels` | 播放、暂停、全屏、管理员入口等所有常用按钮文字 |

## `config/points.json`：点位与视频

`points` 数组可任意增减，每一项对应一个页面、一个底部按钮和一条滑轨位置。

```json
{
  "id": "p05",
  "order": 50,
  "title": "第五展项完整标题",
  "navLabel": "按钮短名称",
  "subtitle": "页面说明文字",
  "videoPath": "content/videos/p05.mp4",
  "posterPath": "content/posters/p05.svg",
  "backgroundPath": "content/backgrounds/p05.png",
  "mascotKey": "main",
  "positionMm": null,
  "enabled": true
}
```

- `id`：数字人 API 与滑轨控制使用的稳定编号，新增后不要随意修改。
- `order`：底部按钮和自动巡展的顺序。
- `title`、`navLabel`、`subtitle`：页面和按钮文字，不需要改前端代码。
- `videoPath`、`posterPath`、`backgroundPath`：对应素材路径。
- `mascotKey`：`main`、`moving`、`playing`、`guide` 四只玩偶；不填会自动循环。
- `positionMm`：现场校准后的绝对毫米坐标；保持 `null` 时真实硬件会拒绝移动。
- `enabled`：`false` 时隐藏该点位，也不会参与轮播。

`points.json` 还保留一个 `p00`：`visible: false`、`positionMm: 0`。它是机械原点，不显示为页面或按钮；“回原点”会移动到此位置。当前四个展示点的方向已按厂家确认设置为负坐标：`-1600`、`-3200`、`-4800`、`-6400`。

## `config/machine.json`：滑轨通讯

| 字段 | 用途 |
| --- | --- |
| `provider` | 开发时为 `mock`，现场联调后改 `tcp` |
| `network.host` | 控制器 IP，目前为 `192.168.1.104` |
| `network.port` | 控制器端口，协议默认 `8080` |
| `network.sharedKey` | 厂家启用密钥时才填写；当前留空 |

不要在未校准 `positionMm` 前把 `provider` 改成 `tcp`。

## WakeFusion 动作文字与启用状态

不要直接编辑 `config/wakefusion.json`。管理员登录后访问：

```text
http://127.0.0.1:8000/subscriptconfig.html
```

该页面只允许修改动作名称、说明、正向/反向关键词和启用状态，并自动更新 `actionsHash`。保存前必须停止自动巡展、等待滑轨静止并停止视频播放。禁用动作后，WakeFusion 使用的 0 基索引会按当前启用数组重新编号。
